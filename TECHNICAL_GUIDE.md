# Technical Deep Dive

This guide provides a detailed look into the core engines and native integrations that power the Geo Tag Camera App.

## 📐 Algorithmic Engines

### 📄 Document Warp (Homography)
The `DocWarpService` handles perspective correction for scanned documents using an 8-DOF (Degrees of Freedom) Homography mapping.

#### Mathematical Foundation (DLT)
The service implements a **Direct Linear Transform (DLT)** solver. Given four source points $(s_i)$ from the crop tool and four destination points $(d_i)$ representing the rectangular output:
- **Matrix Construction**: It builds a $8 \times 8$ matrix $A$ representing the equations $x_{src} = \frac{h_{11}x_{dst} + h_{12}y_{dst} + h_{13}}{h_{31}x_{dst} + h_{32}y_{dst} + 1}$.
- **Gauss-Jordan Elimination**: The app implements a standard Gaussian elimination solver to find the projection coefficients.
- **Bilinear Interpolation**: When rendering the final document, the engine uses bilinear interpolation to ensure the warped text remains sharp and legible, avoiding pixelation.

## 🔗 Native Connectivity (Method Channels)

The app utilizes specialized channels to bridge Flutter and Native Android (Kotlin).

### 🎥 Video Overlay Channel (`video_overlay_channel`)
Used for burning high-fidelity geotag overlays onto raw `.mp4` files.
- **Input Parameters**:
  - `inputPath`: URI of the raw video recorded by the camera.
  - `overlayPath`: URI of a high-res PNG generated by Flutter containing the minimap and address.
  - `outputPath`: Destination URI for the final processed video.
- **Native Implementation**: Uses the **Media3 Transformer** API. The `VideoOverlayMuxer` class creates a `BitmapOverlay` effect that is composed onto the video stream using hardware-accelerated shaders.

### 🖼 EXIF Channel (`exif_channel`)
Writes GPS coordinates directly into the metadata headers of captured photos.
- **Method**: `writeExif`
- **Implementation**: Utilizes `androidx.exifinterface.media.ExifInterface`. This ensures that photo GPS data is visible to OS galleries and professional mapping tools.

## 📱 Responsive UI Engine

The `ResponsiveHelper` utility drives the app's adaptive design.

### Scaling Logic
Instead of fixed values, the app uses a **Multiplier Strategy**:
- **Mobile**: Multiplier of `1.0` (Base).
- **Tablet**: Multiplier of `1.15`.
- **Desktop**: Multiplier of `1.3`.

This ensures that UI elements like buttons, icons, and text scale proportionally based on screen density rather than just fixed breakpoints, providing a premium feel on all devices.

## 💾 Data Persistence Specification

### Sidecar Files (`.geo.json`)
For every video recorded, the app generates a JSON sidecar file containing extended metadata:
```json
{
  "videoPath": "/storage/.../VIDEO_123.mp4",
  "latitude": 12.3456,
  "longitude": 78.9012,
  "address": "123 Main St, New York",
  "recordingDuration": 45,
  "createdAt": "2024-04-14T..."
}
```
This enables fast retrieval of location data without re-parsing the video file or relying solely on external databases.
